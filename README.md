# A national biopsy-anchored benchmark reveals a CT performance ceiling for donor liver macrosteatosis assessment

Official implementation accompanying the manuscript.

Repository: https://github.com/sayoni-c98/liver-transplant-project

## Summary

Donor liver macrovesicular steatosis is a major determinant of organ acceptance in liver transplantation. This repository accompanies a national-scale benchmark study evaluating CT-based prediction of biopsy-confirmed donor liver macrovesicular steatosis (≥30%) using attenuation-based biomarkers, topological descriptors, deep 3D imaging representations, and multimodal machine-learning models.

Using 2,709 biopsy-verified deceased donor livers, we demonstrate a practical CT discrimination ceiling (ROC-AUC ≈ 0.78–0.82) that is not substantially exceeded by modern machine-learning approaches, including topological and deep imaging models.
